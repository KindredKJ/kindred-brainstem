# DCML experience model

`experiences_v2` stores session/mission, input, goal, strategy, instrument, context, prediction, observation, evidence, criteria, reward, cost, latency, uncertainty, intervention, failure, causal attribution, confidence, approval, provenance, privacy, and retention. States are `UNVERIFIED`, `VERIFIED`, `APPROVED_FOR_LEARNING`, and retained terminal governance states.

Generated output, local artifacts, and simulated outcomes do not verify external claims. Passing tests, repository changes, external evidence, financial evidence, and founder confirmation have distinct quality. Only verified experiences with a valid signed learning approval can enter a dataset.
