# DCML dataset governance

Datasets are deterministic manifests over signed, approved, verified experiences. They record source IDs, approval IDs, exclusions, deduplication, contamination, privacy review, seeded train/validation/test splits, target, evaluator, and immutable SHA-256 hash. Restricted records, detected secrets, duplicates, rejected/unapproved records, and private telemetry are excluded. Split overlap is rejected.
