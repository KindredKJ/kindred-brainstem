# Strata Data Port authority map

The canonical order is **Protocol → Tesseract → Unified Quad Runtime ↕ StrataFortress → Modular Core**. Port Zero is the protected anchor inside the Unified Quad Runtime. External ports are Y-axis boundaries and cannot call BRAINSTEM or bypass Port Zero.

This package implements only BRAINSTEM's protected client. It verifies a cryptographic authorization bound to `request_id` and `payload_hash`, requires HTTPS and mutual TLS, initializes correlation/trace identity through the contract, persists an outbox and transition evidence, and fails without fallback. Discovery never implies authorization.

Domain authority remains with G3T Connected, RetroBank/A2A, Kindred WATT, Kindred Cloud, IAMI/IAMI-X, Emit Core, and Kindred One respectively. Provider output cannot become verified truth without domain reconciliation and evidence verification.
